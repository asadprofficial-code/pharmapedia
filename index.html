About this project

PharmaPedia (Demonstration) is an educational website made for the Pharm-D IT lab. It lets a pharmacy student browse medicines, see each medicine's class, use, mechanism of action and an adverse effect, and test themselves with a practice quiz.

  • Explorer: search, filter by body system, sort, and flip cards to see the mechanism.
  • Practice Quiz: 10 questions with instant feedback and a final score.
  • Offline: one HTML file, no internet, no libraries.

    AI declaration

    An AI development tool was used to build the layout, styling, animations, search/filter/sort logic and quiz engine. It was not used to write any dose, strength, frequency, interaction, contraindication or schedule. Quiz questions are generated automatically from the student's own medicine data, so every correct answer comes from that data.

    Privacy & safety

    • No login, no sign-up, no name boxes. Nothing you type or click is stored or sent anywhere.
    • No real patient information is used.
    • This site teaches; it does not advise any person on what to take.
    • Not the website of any real pharmacy, hospital or company.
